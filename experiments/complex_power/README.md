# Complex powers

The scalar label is `Re(exp(-i*25deg) z^p) - offset` on the unit disk. The
stored historical offset in `config.json` is deliberately retained for exact
query-manifest parity. TRIO uses Q128 Broken-Power experts and standard random
initialization. Projection certificates are guarantees for the frozen learned
model; true-DGP feasibility is audited independently at tolerance 1e-6.
